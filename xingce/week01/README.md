# Week 01 · 资料分析(基础)

> 阶段①第 1 周　|　模块:资料分析　|　优先级 ⭐⭐⭐(必拿分)

## 本周目标
资料分析是行测**最该拿满分**的模块——题目不难,难在"快"和"准"。本周打通两件事:
1. **速算能力**:截位、估算、首数,把计算时间压下来
2. **核心公式**:增长、比重、平均数、倍数,看到问题秒反应用哪个公式

## 每日安排
| Day | 主题 |
|---|---|
| Day 01 | 资料分析入门 + 速算三板斧(截位/估算/首数) |
| Day 02 | 增长:基期、现期、增长量、增长率 |
| Day 03 | 增长进阶:混合增长率、年均增长、隔年增长 |
| Day 04 | 比重问题(现期/基期/变化升降) |
| Day 05 | 平均数、倍数、比值 |
| Day 06 | 综合材料阅读 + 多公式综合题 |
| Day 07 | 周复盘:错题二刷 + 限时综合练习一套 |

## 本周目标值
- 资料分析专项正确率 → **85%+**
- 单篇(5题)用时 → 逐步压到 **6 分钟以内**

## 题库建议
粉笔「资料分析」专项 → 按题型练(增长率、比重…),每个专题刷够 30 题再进下一个。
