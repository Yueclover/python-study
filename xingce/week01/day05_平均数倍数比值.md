# Day 05 · 平均数 / 倍数 / 比值

## 🎯 今日方法要点(先学,约35min)

### 一、平均数
- **现期平均数 = 总量 / 份数**(如:总产值 / 企业数)
- **基期平均数 = 基期总量 / 基期份数 = 现期平均数 × (1+份数r) / (1+总量r)**
  - 即现期平均 × (1+分母增长率)/(1+分子增长率)
- **平均数的增长率**(已知总量增长率 a、份数增长率 b):
```
平均数增长率 = (a − b) / (1 + b)
```
- **判断平均数升降**:总量增长率 > 份数增长率 → 平均数上升(同比重逻辑)。

### 二、倍数与"是……的几倍 / 多几倍"
- **A 是 B 的几倍** → A / B
- **A 比 B 多几倍** → A/B − 1
- ⚠️ "多 1 倍" = 多 100% = 变成 2 倍,别混。

### 三、比值(两个量的比)
- 现期比值 = A现期 / B现期
- 基期比值 = 现期比值 × (1+B增长率)/(1+A增长率)
- 升降判断:A 增长率 > B 增长率 → 比值上升

> 📌 规律统一:**比重、平均数、比值** 这三类"分式型"指标,
> 升降都看**分子增长率 vs 分母增长率**,基期都乘 **(1+分母r)/(1+分子r)**。一通百通。

### 四、速算技巧
- 平均数题先想清"谁是总量(分子)、谁是份数(分母)"。
- 倍数题看清"是……倍"还是"多……倍",差一个 1。

### 五、易错提醒
- 平均数基期别忘了是 **(1+分母r)/(1+分子r)**,和比重同构。
- "增长 N 倍" → 现期 = 基期 ×(N+1)。

## ✍️ 巩固练习(先自测,再看答案)

> **材料:** 2023 年某市规模以上工业企业 500 家,实现总产值 2000 亿元;2022 年企业 450 家,总产值 1600 亿元。

**1.** 2023 年平均每家企业产值(现期平均数)是?
　A. 4 亿元　B. 3.56 亿元　C. 5 亿元　D. 3.2 亿元

**2.** 2022 年平均每家企业产值约是?
　A. 3.56 亿元　B. 4 亿元　C. 3.2 亿元　D. 4.44 亿元

**3.** 2023 年平均产值约是 2022 年的多少倍?
　A. 1.12 倍　B. 0.12 倍　C. 1.25 倍　D. 2 倍

**4.** 2023 年企业平均产值同比增长率约为?
　A. 12.5%　B. 25%　C. 11.1%　D. 14%

**5.**(辨析)"A 是 B 的 3 倍"与"A 比 B 多 3 倍",两者关系是?
　A. 完全相同　B. 前者 A=3B,后者 A=4B　C. 前者 A=4B,后者 A=3B　D. 无法比较

<details>
<summary>👉 点击查看答案与详解</summary>

**1. A**　现期平均 = 总量/份数 = 2000/500 = **4 亿元**。
**2. A**　基期平均 = 1600/450 ≈ **3.56 亿元**。
**3. A**　4 ÷ 3.56 ≈ **1.12 倍**("是…倍"用除法)。
**4. A**　平均数增长率 = (总量r − 份数r)/(1+份数r);总量r=400/1600=25%,份数r=50/450≈11.1% → (25%−11.1%)/1.111 ≈ **12.5%**。
**5. B**　"是 3 倍" → A=3B;"多 3 倍" → A=B+3B=**4B**。差一个 1,务必看清。

</details>
