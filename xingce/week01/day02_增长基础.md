# Day 02 · 增长:基期 / 现期 / 增长量 / 增长率

## 🎯 今日方法要点(先学,约35min)

### 一、四个核心概念
- **现期**:现在这一期的值(题目通常直接给)
- **基期**:作为比较基础的上一期
- **增长量**:现期 − 基期(变化的绝对量)
- **增长率 r**:增长量 ÷ 基期(变化的相对比例)

### 二、核心公式(背到秒反应)

| 求什么 | 公式 |
|---|---|
| 增长率 r | r = 增长量 / 基期 = (现期 − 基期) / 基期 |
| 现期 | 现期 = 基期 × (1 + r) |
| **基期** | 基期 = 现期 / (1 + r) |
| **增长量** | 增长量 = 现期 − 基期 = 现期 × r / (1 + r) |

> ⭐ 两个最常考、最容易记混的:
> - **求基期** → 用「除以 (1+r)」　`基期 = 现期 / (1+r)`
> - **求增长量** → 用「现期 × r/(1+r)」(已知现期和增长率时最快)

### 三、速算技巧

**1. 求基期(现期 ÷ (1+r))→ 用"化除为乘 + 截位"**
- 例:现期 5600,r = 12% → 基期 = 5600 / 1.12 ≈ 5000

**2. 增长量比较大小 → 看"现期大且增长率高"**
- 不用精算,现期和 r 都更大的,增长量一般更大。

**3. 增长量 = 现期 × r/(1+r) 的分数化简**
- r=25%=1/4 → r/(1+r)= (1/4)/(5/4)=1/5,增长量=现期×1/5
- 常见:r=10%→1/11,r=20%→1/6,r=25%→1/5,r=50%→1/3

### 四、易错提醒
- "增长了百分之几" = 求**增长率**;"增长了多少(万元/人)" = 求**增长量**,别看错。
- "比……增长" 的基准是**后面那个量**(基期)。
- 百分点 ≠ 百分比:`从 10% 到 13% 是增长了 3 个百分点,而非增长 3%`。
